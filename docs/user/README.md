# ezyPlayer documentation

ezyPlayer is a cue player for live events: sound effects, music, video, stills
and slides, fired from a grid of cues or played as a background playlist.

| Guide | Read it when |
|---|---|
| [Quick Start](quick-start.md) | You have just installed ezyPlayer and want your first cue playing in ten minutes. |
| [User Guide](user-guide.md) | You are building a show and want to know what every control does. |
| [Keyboard Shortcuts](keyboard-shortcuts.md) | You want a one-page reference to print and keep at the desk. |
| [Show-Day Checklist](show-day-checklist.md) | Before every show. |
| [Troubleshooting](troubleshooting.md) | Something does not behave as expected. |

These guides describe ezyPlayer 0.9 (beta) on Windows and Linux.
