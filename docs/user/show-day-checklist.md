# Show-Day Checklist

No software can promise it will never fail, and neither can the computer, the
audio interface or the cables. This checklist helps you keep the risk low and
recover fast.

## The day before

- [ ] **Licence activated** on the show computer and on the backup computer
      (Settings → License). Demo mode mutes the sound briefly every few minutes.
- [ ] **Show folder on a local drive**, not on a network share or a cloud-synced
      folder that could go offline or re-sync during the show.
- [ ] **Show saved** (FILES → Save) and the **whole show folder** copied to the
      **backup computer**. Open it there once and check there is no FILE MISSING.
- [ ] Audio and video settings checked on the backup computer too: they belong to
      each computer, not to the show.
- [ ] Operating system and driver **updates done or postponed**: never let a
      computer update itself on show day.
- [ ] Notifications, antivirus scans and automatic backups **paused** for the show.
- [ ] Power settings: the computer on mains power, and USB selective suspend
      disabled if your audio interface is USB.

## At the venue

- [ ] Audio interface connected **before** starting ezyPlayer.
- [ ] **Settings → Devices**: **Test tone** on every channel you use, and check it
      arrives at the right place in the mixer.
- [ ] **Settings → Routing**: Cues, Playlist, Preview and colour outputs correct.
- [ ] Second screen connected; click **VIDEO** and check the output appears on the
      right screen and the blackout screen is the one you want.
- [ ] **No FILE MISSING or ERROR** tiles on any of the four pages.
- [ ] Run the show once with **GO** from the first cue to the last, including
      pre-waits, auto-continue chains, ducking and video.
- [ ] Check levels with the actual PA at show volume.
- [ ] Check that **Esc** (Stop All) and the blackout button do what you expect.

## Just before doors

- [ ] Select the first cue (NEXT) of the show.
- [ ] Switch to **● LIVE** so nothing can be moved or edited by accident.
- [ ] Close other applications, especially those that use audio (video calls,
      music players, browsers playing media).
- [ ] Backup computer running with the same show loaded, or a fallback playback
      source ready to switch to at the mixer.

## If something goes wrong

1. **Keep the show going first**: switch to the backup at the mixer or the
   switcher.
2. Note the time and what happened.
3. After the show, open **Settings → Devices → Open logs folder** and send us the
   latest log file with your notes. See [Troubleshooting](troubleshooting.md).
