# Keyboard Shortcuts

Shortcuts do not act while you are typing in a text field or while the cue editor
is open.

## Everywhere

| Key | Action |
|---|---|
| **9** | Cue view |
| **0** | Playlist view |
| **F11** | Full-screen main window |

## Cue view

| Key | Action |
|---|---|
| **Space** | GO: fire the NEXT cue and advance |
| **Esc** | Stop all cues (panic) |
| **Enter** | Stop the selected cue (with fade) |
| **P** | Pause / resume the selected cue |
| **← → ↑ ↓** | Move the selection (NEXT) |
| **Page Up / Page Down** | Previous / next page |
| Cue key | Fire that cue from the beginning |
| **Ctrl** + cue key | Preview the cue (Preview bus) |
| **Ctrl** + click | Preview the cue |
| **-** | Slides: next page |
| **.** | Slides: previous page |

Cue keys, on every page:

```
1 2 3 4 5 6 7 8
Q W E R T Y U I
A S D F G H J K
Z X C V B N M ,
```

## Playlist view

| Key | Action |
|---|---|
| **↑ ↓** | Select a track |
| **Enter** | Play the selected track |
| **Space** | Play / pause |
| **Esc** | Stop the playlist |
